# Homepage Wireframe

## Header

`Northstar Credit` · Home · Start Review · Cases · Portfolio · Methodology · Help

## First viewport

### Should this company receive this loan?

Review financial strength, debt capacity, stress resilience, and lending terms in one guided workflow.

`Start a guided credit review`  `Open a sample case`

The sample action opens the stable synthetic case decision directly. The first viewport contains no ratios or decorative badges beyond the two actions.

## Pinned sample decision band

Label: `Sample case — Meridian Industrial (synthetic)`

1. Repayment outlook — `DSCR 1.60x` — recurring cash flow covers scheduled payments with a 60% cushion.
2. Recommended loan amount — `$24.0M of $30.0M requested` — limited by DSCR capacity.
3. Stress resilience — `Downside holds; severe breaches` — leverage covenant first breaches in year two.

Each outcome has a `Why?` action. No more than these three outcome cards appear.

## Workflow band

1. Add company.
2. Enter loan request.
3. Review stress results.
4. Receive recommendation.

## Recent cases

At most five rows: company, status, recommendation, last updated, open.

## Trust and footer

Transparent calculations · no black-box approval · details on demand · educational project. Footer links Methodology, Model limitations, Data sources, and Disclaimer.

## Design direction

Editorial banking brief: true white background; deep ink/navy typography; dark accessible copper for interactive accents; brighter copper only for decorative rules; compact tabular figures; crisp borders; restrained radii; generous whitespace; minimal motion. Every color token is contrast-tested before implementation.
