# Collaboration Decision Protocol

For high-impact product, financial, architecture, accessibility, security, or scope decisions:

1. Codex writes an independent proposal.
2. Claude writes an independent proposal without seeing Codex's conclusion.
3. The proposals are compared in a decision record.
4. Each agent challenges the other's assumptions.
5. At least one counterexample or failure mode is tested.
6. Evidence determines the decision; simpler and more reversible choices win when evidence is otherwise balanced.
7. The record names the author, reviewer, model, risks, reversibility, and rejected alternatives.

No file is accepted until the non-author reviews every diff hunk and returns an explicit disposition. Required fixes are implemented and re-reviewed. Security, data loss, and financial-integrity objections cannot be waived while material and unresolved.
